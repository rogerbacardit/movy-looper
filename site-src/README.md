# site-src: sources of the docs site

`../site/` is generated and static (open `site/index.html`). Hand-edit directly in `site/`: `assets/app.js`, `assets/style.css`, `assets/move.svg`.

Generated by `python3 build.py` (needs `beautifulsoup4`):
- `index.src.html` (Spanish, no keys) -> `../site/index.html`: text elements get `data-i18n` / `data-i18n-html` / `data-i18n-attr` keys (`<section>.<n>`). Elements already carrying a manual key (`v08.*`, `cs.*`, `hero.legend`) are kept as is, so new text should use manual keys: auto-numbering shifts when elements are inserted before others.
- `jsstrings.py`: Spanish strings used by `app.js` (`t('key')`).
- Spanish dictionary -> `../site/assets/i18n/es.js`.
- `translations/<lang>.json` (en de fr pt ja it ca) -> `../site/assets/i18n/<lang>.js`. build.py warns about missing/extra keys per language (a missing key falls back to Spanish at runtime).

Adding text: put it in `index.src.html` (manual key) or `jsstrings.py`, add the key to every `translations/*.json` (`add_extra.py` shows how), run `python3 build.py`.

`shots.mjs`: headless Chrome screenshots + console-error / horizontal-scroll check, e.g. `node shots.mjs /tmp/shots es,en 1400,390 hero-device,col1@700`.
